# Academic Research Website

This project is a final-year university research website designed to present an academic concept in a professional, visually engaging, and easy-to-navigate format. It acts as a digital portfolio and information hub for a research study, showing the project idea, objectives, milestones, research contributions, documentation, presentations, and team details.

## Project Idea
The website presents a research-based solution related to smart and responsive service systems. It explains a real-world problem and how the project proposes to address it through structured research, technical design, and academic documentation.

The main purpose is not to build a full production application, but to create a strong academic presentation that communicates:
- the research domain,
- the problem being solved,
- the project contributions,
- the timeline and milestones,
- supporting documents and presentations,
- the team and supervisor information.

## Overall Goal
This project helps students communicate their research work in a format that can be shown to lecturers, evaluators, and viva panels. It demonstrates how an academic idea can be transformed into a clean, professional online presence using static web technologies.

## Key Features
- Single-page academic website with smooth scrolling navigation
- Responsive layout for desktop and mobile viewing
- Research domain and contribution sections
- Milestone timeline for project progress
- Documents section with proposal previews and download links
- Presentation and team information area
- Clean academic visual style using HTML, CSS, and JavaScript
- Local SVG and document assets for offline project presentation

## Technologies Used
- HTML5
- CSS3
- SVG illustrations
- Local PDF files for research documentation

## Project Structure
- `index.html` – main landing page and website structure
- `assets/` – CSS, JavaScript, images, and UI-related assets
- `docs/` – supporting research documents and project files

## How to Run
1. Open the project folder.
2. Double-click `index.html` in a browser, or use a local web server if preferred.
3. Navigate through the sections using the top navigation menu.

## Important Notes for Students
This project is a research website and academic presentation platform, not a live AI system, real booking service, or production-ready software product.

Important points to remember:
- The content is mainly informational and presentation-focused.
- Research storytelling and visuals are meant to explain the concept clearly.
- Any document links must be checked and verified before final submission.
- OneDrive or external file embedding may fail depending on access permissions, so public-access sharing and testing are required.
- Confidential or private documents should never be publicly exposed.
- Final submission should include official milestone dates, updated reports, and any required university documents.

## Recommended Final Submission Checklist
- Confirm all milestone dates and marks are correct
- Add required project reports, charters, and slides when available
- Verify all links and embedded PDF previews work properly
- Test the site on the target devices and browsers
- Check file size limits before submission
- Ensure the project remains academically appropriate and professionally presented
